# 我一直属于这里

## 硬卧回家
### 杭州站
- 这是我第一次来杭州站，确实有点出乎我的意料，因为杭州站并不像东站那么高级，反倒是更像我老家的旧火车站，给人一种和杭州“大都市”形象不相符的感觉。在这里，我看到了更多的和老家相似的乘车场景，拿着大包小包的劳动人民，哭闹嬉戏的小朋友，插队、喧闹、争吵，这都和我从小长大所经历的场景如出一辙。
- 我站在里面，尽量将自己融入其中。因为高中在重庆主城读，大学在国内顶尖大学就读，所以我一度认为自己已经摆脱了“社会底层”的标签，已经成为了所谓的“精英”。当我傲视身边的底层人民，我感到了深深的愧疚，因为我父母也是他们的一员，但是我很爱我的父母，我也知道，他们之所以没能摆脱这个阶层是因为家庭和时代的因素，并不全是因为他们自己不努力，而我非常幸运，出生在一个非常有爱的家庭，我的父母很注重孩子的学习，愿意投入大量时间和金钱在教育上，这也是为什么我能从小县城到重庆巴蜀，再从巴蜀到浙江大学，要是没有我的父母，没有这两位所谓的“底层人民”，我肯定也没有今天的成就。
- 在杭州站，我看到了很多外出打工的青年，看到了很多跟在年轻父母身后的小朋友。我会觉得，这些青年没有我体面，没有我穿得好看，没有我有气质；我会觉得这些小朋友很可怜，自己的父母不会很好的管教自己，不会很在意自己的学习，不会带自己去看这个精彩的世界……这让我想到了“自由平等主义”，这世界上有太多的不确定因素，我们的成就并不完全是我们努力的结果，要是我的父母也就是普通的外出打工人，要是我也从小放养，我可能还没他们能干。
