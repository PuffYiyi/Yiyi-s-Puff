# 人生桩桩件件，该如何码放

>近日读了刘震云的《一句顶一万句》，读来只觉得小说比较好理解，其中人物的心理也总是让我联想到自己身边的人、生活以及自己。时代的故事读来总是恢弘而又沉重，我在脑海中构想了一个延津，构想了一个又一个画面，从小说人物的身上看到了同样出身农村的祖上，看到了那个时代人与人的复杂关系，看到了人心中的迷茫与彷徨，那是小说人物的生活现状，也是我的祖辈。

## 心里的沉重
- 小说中，人物兜兜转转、弯弯绕绕，翻山越岭只为寻找一个能说得上话的人，动辄几百里的路程，走上好几天。“一件一件码放”，码放整齐，事情也就清楚了。对于那个年代，普遍文化水平较低时，光是能说清楚话、理清事情便已是能干。这让我想到了b站某个up主，视频内容就是让农村老人读一些纸条、回答一些问题，或许他们就是从那个时代过来还健在的人，他们的语言逻辑能力还符合那个年代的普遍水平。
## 时代的变迁
- 小说从出延津到入延津，有人离开伤心地，有人为寻答案入此地，过去几代人兜兜转转终是回到了这里。不仅是吴摩西和牛爱国，单就是我也是充满了对时代和故土的留恋。几代人，串起了整个时代，从步行几百里寻人，到电话联系小轿车普及，时代的进步与发展也映现其中，但无论如何发展，总有人始终保持着原来的生活方式，那些固守家乡的人，仍然怀着对土地的执着与眷念，未曾离开。
- 每一代人都有自己独有的时代印记以及思考方式，老一辈人，困囿于父子、夫妻、婆媳等诸多关系，一代又一代的重演，作为21世纪青年我们大多不能理解为什么他们会那么觉得，或许在我们看来，“00后整顿xx”，我们拿得起放得下、不委屈自己，倒不像老一代人。但还是得多些理解，毕竟时代背景不同，思考方式不同，带着“时代的眼镜”去看待他们，不强求他们改变，或许也是一种处理代际关系的好方式。
## “不，还得找”
- 执着于一句话，他从河南到陕西，又到北京，在诺大的城市，去寻找那个未知的人。上一辈人的执着我也是见过的，执着于一亩三分地，执着于利益平等，执着于我比你强。外婆是新中国诞生年代出生的，那个时代或许还像吴摩西的时代，生活无非饿不死、娶妻生子、男女之事、八卦、找点事干，父子辈的关系或许也是如此紧张，据说外婆年轻时对妈妈很凶，老是打她，外婆老了之后妈妈虽无打骂，但也不似我和妈妈这般亲密，或许妈妈对外婆仍有心中的怨恨吧。外婆虽已75，但聊起来自己老家的地，东至哪棵树，西至哪条河，仍然是清楚得很，我偶尔问她要不要回老家，也就1小时路程，她倒是摆手不回，自己生人长大的地方，她倒是不眷念。说来奇怪，我问起妈妈她也是不眷念，说呆了那么多年有什么好想的。我却是不太一样，我总是担心离开家乡，每每想到几十年后我将和老家再无瓜葛便心生感触，或许我也是执着，只是执着的点不太一样罢了。有点好笑，我这个从没有和土地打过交道的人，反倒是对故乡思念最甚。
- 发展太快的时代，总是会忘掉一些人。那部分人看起来显得滑稽，却不自知。老家对面的大伯、二伯，常年为一点利益争来争去，父子、夫妻、八卦，倒是像极了那个时代的人。但这部分人的存在，倒是让乡土生活多了些时代气息与情感，也构成了我记忆的一部分。

## 结语
读此书时总会想到之前读的《平凡的世界》，同样是“平凡的世界”，描绘普通人的生活以及心理，带我们看一幅时代的史诗。
一句顶一万句，为了寻找那一句，我们走过千山万水，说过万句话，却被那一句话指引着方向，困囿在其中。或许书中是一句话，但在我们的生活中，我们都有执着于用一辈子去追寻的东西，“活的是未来，不是过去”，在追寻的过程中也不要忘了生活，觅得快乐的一生。
