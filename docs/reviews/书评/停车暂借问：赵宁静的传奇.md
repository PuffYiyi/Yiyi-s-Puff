# 停车暂借问：赵宁静的传奇


## 契机
- 昨日听一丁推荐了这本书，所以特地下来看一看。反正闲来无事，又是小说作品，所以便两口气阅读完毕，确是余韵悠长。
## 故事

- 上世纪四十年代的三段爱情故事，一是与日本人的青春爱念，二是与爽然的两情相悦，三是与熊应生的夫妻迁就。与日本人，是时代不允许，恰逢日本战败，“什么”人必须归国，否则会被群起而攻之。与爽然，是相逢不当时，他已有婚约又怎能随意妄为，她赌气订婚又怎料他未出口的那一句是求婚，纵使多年之后再相逢，也是在“一夜夫妻”后断了联系。与应生，是夫妻不是爱情，是起初就注定的不和，是向生活妥协的迁就，是一生错过的归宿。
- **故事戛然而止：**爽生赴美不归是震慑人心的。前半生错过的两人本以为可以再续前缘，却最终断了联系。“一夜夫妻”看似是决心相守的前兆，实则是彻底放手前的放纵。难以想象，宁静俯在玄关，期待着来自美国的信件，思念着远方的爱人，反复的下定决心与他共度余生，却被告知永不再见，那千万种可能反复出现，最终只留下赴美不归的结局。她终究只是一个妇人，前脚刚与应生离婚，后脚就被爱人抛弃，虽说以她的坚韧她绝不期待依附任何人，但错过15年再重逢、再离别终归是有些残忍。
- **思考：**最深刻的感受是要和自己爱的人在一起，不要迁就，不要以为自己可以将就。但是在对的时间遇到对的人也很重要，不要蛮横任性，以免错过那个人，留下一生的遗憾。
